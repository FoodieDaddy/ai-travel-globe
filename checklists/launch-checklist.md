# 上线 Checklist

## 域名与 HTTPS

- [ ] 前端域名配置完成。
- [ ] API 域名配置完成。
- [ ] HTTPS 证书有效。
- [ ] HTTP 自动跳转 HTTPS。

## 环境变量

- [ ] AI_API_KEY 已配置。
- [ ] GEOCODING_API_KEY 已配置。
- [ ] DATABASE_URL 已配置。
- [ ] CORS_ORIGIN 已配置。
- [ ] NODE_ENV=production。

## 数据库

- [ ] 表结构初始化完成。
- [ ] 数据库不暴露公网。
- [ ] 业务用户不是超级管理员。
- [ ] 自动备份开启。
- [ ] 备份恢复测试通过。

## 服务器

- [ ] 只开放 80/443/必要 SSH。
- [ ] 后端端口只监听 127.0.0.1 或内网。
- [ ] Nginx 反向代理正常。
- [ ] 服务配置开机自启。
- [ ] 日志路径确认。

## 监控

- [ ] API 错误率监控。
- [ ] 服务器 CPU/内存/磁盘监控。
- [ ] 数据库连接数监控。
- [ ] AI 调用失败告警。

## 产品

- [ ] 页面有免责声明。
- [ ] 失败提示友好。
- [ ] 移动端可用。
- [ ] 分享链接正常。
- [ ] 录制演示视频。

## 成本

- [ ] AI 调用有限流。
- [ ] 地理编码有缓存。
- [ ] 静态资源走 CDN。
- [ ] 日志不会无限增长。
