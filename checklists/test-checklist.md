# 测试 Checklist

## 功能测试

- [ ] 生成日本 7 日路线。
- [ ] 生成欧洲 14 日路线。
- [ ] 生成中国 5 日路线。
- [ ] 偏好为空时有默认路线。
- [ ] 天数为 1 时正常。
- [ ] 天数为 30 时正常。
- [ ] 目的地不存在时有错误提示。

## AI 输出测试

- [ ] AI 输出合法 JSON。
- [ ] itinerary 长度等于 days。
- [ ] places 中城市天数总和等于 days。
- [ ] 经纬度为 null 时能补全。
- [ ] 城市重复时能去重。

## 地图测试

- [ ] 点位显示位置正确。
- [ ] 飞线方向正确。
- [ ] 点击点位弹出信息。
- [ ] 点击卡片镜头移动。
- [ ] WebGL 不可用时有提示。

## API 测试

- [ ] `/health` 正常。
- [ ] `/api/travel-plans/generate` 正常。
- [ ] `/api/travel-plans/:id` 正常。
- [ ] 输入不合法返回 400。
- [ ] AI 超时返回友好错误。

## 安全测试

- [ ] 前端源码不包含 AI API Key。
- [ ] CORS 只允许指定域名。
- [ ] 生成接口有限流。
- [ ] 用户输入超长会被拒绝。
- [ ] Prompt Injection 不会泄露系统提示。

## 性能测试

- [ ] 首屏 3 秒内可见。
- [ ] 生成路线 30 秒内返回。
- [ ] 3D 地球交互不卡死。
- [ ] 100 个点位以内可流畅运行。
