# 00. 产品范围

## 一句话定位

一个用 AI 生成旅行路线，并通过 3D 地球交互展示路线、城市、景点和行程卡片的 Web 应用。

## 核心用户

1. 想快速规划旅行路线的普通用户。
2. 内容创作者，用它生成旅行视频或分享页。
3. 旅行博主，用它做互动路线展示。
4. 旅游服务商，用它展示定制路线。

## 核心场景

### 场景 1：AI 生成旅行路线

用户输入：

```text
我想 7 天玩日本，喜欢动漫、美食和自然风景，预算中等。
```

系统输出：

- 东京 3 天。
- 京都 2 天。
- 大阪 2 天。
- 每天推荐景点和理由。
- 每个城市的经纬度。
- 城市之间的顺序路线。

### 场景 2：3D 地球展示

展示内容：

- 地球自动旋转。
- 城市点位高亮。
- 城市之间有飞线动画。
- 鼠标悬浮显示城市信息。
- 点击城市后镜头飞过去。

### 场景 3：分享行程

输出一个分享链接：

```text
https://travel.example.com/share/abc123
```

别人打开后可以看到同一条路线。

## MVP 功能范围

必须做：

- 旅行需求输入框。
- AI 生成结构化路线。
- 3D 地球展示点位。
- 飞线动画。
- 左侧行程卡片。
- 点击城市定位。
- 保存路线到数据库。

可以后做：

- 登录注册。
- 收藏路线。
- AI 生图封面。
- 地图导出视频。
- 多语言。
- 预算估算。
- 酒店/机票接口。

## 暂不做

第一版不做：

- 真实机票酒店预订。
- 支付。
- 复杂多人协作。
- 离线 App。
- 精准交通换乘规划。
- 商业级旅游合规审核。

## 成功标准

MVP 成功标准：

1. 用户输入旅行需求后，30 秒内生成路线。
2. 地球交互流畅，普通笔记本浏览器可运行。
3. AI 返回 JSON 稳定，不频繁格式错误。
4. 生成路线可以保存和重新打开。
5. 整体效果适合录制短视频展示。
